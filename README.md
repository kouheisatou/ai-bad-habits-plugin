# AI悪癖図鑑 プラグイン

AIが出したもの（文章・コード・UI・命名・構成など）に不満を言ったとき、その指摘を
[AI悪癖図鑑](https://ai-bad-habit.com) の自分のアカウントへ**非公開で**記録する。
溜まった癖は、次に何かを作るときに反映される。

## 何が起きるか

```
「この文、AIっぽいから直して」
   ↓
Claude が文章を直す
   ↓
「図鑑に記録します: 〜を大切にする、で締めがち」と確認を出す
   ↓
承諾すると、自分のアカウントに非公開で貯まる
```

記録は**必ず非公開**で入る。公開したいものは、図鑑のマイページで自分で切り替える。
プラグイン側から公開する手段は用意していない。

## 導入

プラグインを入れるだけでよい。トークンの発行も環境変数の設定も要らない。

```
/plugin marketplace add kouheisatou/ai-bad-habits
/plugin install ai-bad-habits@ai-bad-habits
```

初めて記録しようとしたときに**ブラウザが自動で開く**。
Googleでログインして「許可する」を押せば、そのまま繋がる。

すでにログイン済みなら、ボタンを1回押すだけで終わる。

## 記録されるもの

| 項目 | 例 |
|---|---|
| 癖の要約 | 「〜を大切にする」で締めがち |
| 修正前 | 品質を大切にすることが重要です。 |
| 修正後 | レビューで落ちる箇所が減ります。 |
| 指摘の言葉 | なんか薄っぺらい |

**送らないもの**: ファイルパス、リポジトリ名、URL、メールアドレス、
指摘の対象になっていない周辺の文章。

記録の前に必ず内容が表示される。断れば記録されない。

## 何が記録されるか

**AIの出力の癖に対する不満なら、種類を問わず拾う。**

| 対象 | 指摘の例 |
|---|---|
| 文章 | 「薄っぺらい」「まとめは要らない」 |
| コード | 「この関数名が不自然」「頼んでないのに例外クラス作るな」 |
| UI | 「枠で囲いすぎ」「情報詰め込みすぎ」 |
| 構成・命名 | 「順番がおかしい」「名前が長い」 |

### 記録されないもの

- 事実の誤りの訂正（癖ではなく単なる間違いのため）
- 仕様や要件の変更（出来への不満ではないため）
- 環境やツールの問題（ビルドが通らない、など）

## 確認を省きたいとき

既定では**毎回確認**が出る。うるさければ

```
「以降は確認しないで」
```

と言えば、次から確認なしで記録される。
マイページの設定からいつでも戻せる。

## 接続を切りたいとき

https://ai-bad-habit.com/settings/plugin に繋がっているエディタが並ぶ。
そこで切断すると、そのエディタからは記録できなくなる。

## 画面での案内

https://ai-bad-habit.com/guide/plugin に同じ内容を置いてある。

## MCPサーバーを入れずにスキルだけ使う場合

記録はできないが、スキル自体は動く。文章の修正だけが行われる。
